# CoffeeChat — Interactive Competitive Strategy Platform

An interactive, single-page website that presents the **CoffeeChat Competitive
Landscape & Strategic Screen** (career + company intelligence for Nigeria & Kenya).

## What's inside
- **Overview** — the "your competitor is your uncle" thesis
- **Competitor map** — Direct / Indirect / Behavioural (tabbed)
- **Porter's Five Forces** — expandable cards with threat meters
- **PESTLE** — expandable factor accordion
- **Lifecycle** — the "two clocks" land-grab view
- **SWOT** — colour-coded quadrants
- **R-W-W screen** — filterable by flag (credible / must-validate / weakness)
- **Verdict** — the five things that must be true

## How to view it
It's one self-contained file — no installation, no build step, no internet needed.

- **Easiest:** double-click `index.html` to open it in any web browser.

## How to put it online for free (GitHub Pages)
1. On GitHub, go to this repo → **Settings** → **Pages**.
2. Under "Build and deployment", set **Source** = *Deploy from a branch*.
3. Pick the branch, set the folder to `/ (root)`, and save.
4. After a minute, your site is live at
   `https://<your-username>.github.io/<repo>/coffeechat/`.

## Editing the content
All the text and data live inside `index.html`. The competitor cards, Five
Forces, PESTLE factors and R-W-W rows are defined as simple lists near the
bottom of the file (in the `<script>` block) — edit those to update the site.
